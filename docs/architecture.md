# SIFE 程序架构

```
sife/
├── sife/                     # 物理与数值核心（numba 加速）
│   ├── constants.py          # CGS 常数；温度一律以 eV 计
│   ├── materials.py          # 材料：<Z>, <Z²>, <A>, ρ0, DT 份额, 冷压参数, 不透明度倍乘
│   ├── eos.py                # 双温费米/理想气体 EOS + 固体冷压
│   ├── transport.py          # 库仑对数, τ_e, Spitzer-Härm κ_e, κ_i, e-i 交换, 不透明度, IB 吸收
│   ├── hydro.py              # 交错网格拉格朗日流体 (1D 平面/柱/球)，预估-校正
│   ├── diffusion.py          # 隐式三温 (Te,Ti,Er) 块三对角求解：热传导+交换+辐射+激光源
│   ├── laser.py              # 一维球对称射线追踪 (Bouguer 不变量, 解析转折点积分)
│   ├── fusion.py             # Bosch-Hale 反应率, 燃耗, α 多角度直线慢化输运
│   ├── simulation.py         # 一维主程序: 网格/靶构建、时间推进、能量账本、诊断、输出
│   ├── hydro_sph.py          # 二维流体: 球极坐标 (r,θ)，径向拉格朗日 + 角向 ALE 重映射
│   ├── diffusion2d.py        # 二维隐式三温扩散 (角向扫描 + 径向 3T 块三对角，多线程)
│   ├── simulation2d.py       # 二维主程序 (轴对称): 扇区激光追踪、燃烧、α 沉积、扰动种子
│   ├── qvalue.py             # Q 值: 靶增益、吸收增益、燃料增益、ηG、工程 Q
│   └── animate.py            # 动画: 一维剖面/r-t 图、二维密度/离子温度图 (MP4 + GIF)
├── benchmarks/               # 验证算例 (run_all.py 一键运行)
├── examples/
│   ├── krf_target.py         # KrF 直接驱动点火靶 (可用 json 参数覆盖)
│   ├── krf_target_2d.py      # 同一靶的二维版本 (照明不均匀性 / 界面扰动)
│   └── plot_krf.py           # 结果作图
├── docs/                     # 调研笔记、架构、结果报告
└── output/                   # 结果 (图、npz、summary.json)
```

## 每个时间步（算子分裂）

1. **激光**：在 tⁿ 的状态上做射线追踪，得到每个网格的电子加热功率 P_dep。
2. **流体**：预估-校正拉格朗日推进 r、u、ρ、e_e、e_i、e_r。人工粘性加热离子；P_r dV 功计入辐射。
3. **三温隐式步**：电子/离子热传导、e-i 交换、辐射发射/吸收/扩散和激光源联立，按向后欧拉推进。用 Picard 迭代滞后非线性系数，把 aT⁴ 线性化，每个网格是 3×3 块，整体用块三对角直接求解。
4. **燃烧**：Bosch-Hale 反应率、燃料消耗；α 能量按多角度直线慢化沉积到电子和离子。
5. **EOS 更新与诊断**，然后选取下一步时间步长。步长取以下限制中的最小值：CFL、温度相对变化 ≤ 15%、体积相对变化 ≤ 8%，并且不跨越激光脉冲表的拐点。

## 能量守恒账本

E_tot(t) − E_tot(0) = E_laser,abs + E_α,dep + W_boundary − E_rad,lost

它作为 `energy_error()` 在每次输出时检查。基准算例中误差 ≲ 10⁻⁵。

## 二维程序（SIFE-2D）

### Godunov ALE 流体（`hydro_ale.py`、`simulation_ale.py`，默认）

为了算出烧蚀面和减速面的 Rayleigh-Taylor 增长，二维流体重写为有限体积 Godunov ALE 格式。`examples/krf_target_2d.py` 默认用它（`--solver ale`），旧格式仍可用 `--solver lag`。

- **网格**：球极坐标扇区网格。角向等分且固定；径向圈 r_i(t) 对所有列相同，随时间移动。网格面积、体积和扫过体积都用解析式计算，几何守恒律（GCL）严格成立。
- **圈的运动**：每圈的速度取该圈所有列径向 HLLC 接触速度 S* 的立体角平均（`Options2D.mesh_motion = "contact"`）。球对称流动中没有质量穿过圈，格式与一维拉格朗日等价，材料界面保持锐利；只有角向扰动部分会产生径向质量流，这正是 RT 增长需要的自由度。若某格相对邻格被压得过小（尺寸比低于初始比的 `mesh_qmin` = 0.2 倍），对应圈会被减速。这一约束只在 Noh 中心这类停滞区起作用。
- **通量**：原始变量 MUSCL 重构（van Leer 限制），在运动面上解 HLLC 黎曼问题，用 Heun 二阶 Runge-Kutta 推进。几何源项采用平衡形式，即 P(A_out − A_in)、P(S_{j+1} − S_j)，再加离心项和科氏项，所以静止的分层状态严格保持静止。外边界是真空自由面（P = 0，外圈随流体运动）；赤道是反射边界。
- **多温度与多材料**：
  - 总能守恒。电子能、辐射能和离子的 pdV 副本按上风输运，并按接触速度计算 −p dV 功。
  - 离子能用双能量法：在非激波区且内能远小于动能时，取 pdV 副本，防止高速内爆壳层的熵被数值误差抬高。
  - 各材料的质量分数 X 和 DT 燃料量做被动输运，混合网格按离子数混合 Z、A。
  - 界面位置取 X 的累积分布等于 0.5 处，动画中画成白线。
- **中心**：最内 2 圈（`core_rings`）是准一维核心，按圈平均。热斑气体其余部分可以自由做角向流动。
- **基准**（ALE 版）：
  - Sedov：激波半径误差 0.34%，能量误差 5×10⁻⁹，角向对称到机器精度。
  - Noh：激波位置 0.202（精确解 0.200），平台密度约 62（精确解 64）。
  - 球面 RT：l = 8 在每 90° 32 个角向网格时，增长率为理论值的 0.91；l = 20 在 64 个网格时为 0.76。旧格式在默认沙漏刚度下增长率为 0。

### 网格与流体（旧格式 `hydro_sph.py`，`--solver lag`）

- **网格**：轴对称球极坐标。节点 (i, j) 位于固定的"辐条" θ_j 上，半径 r[i, j] 随时间变化。i = 0 是球心。默认只算半球 0 ≤ θ ≤ π/2，赤道面取反射边界；`half=False` 时计算整个 0–π。
- **网格体积**：内、外边界在 θ 方向线性插值，体积 V = (2π/3)∫(r_out³ − r_in³) sinθ dθ 用 Gauss 积分计算。对球扇区它是精确的。
- **拉格朗日步**（预估-校正，与一维 VNR 一致）：
  - 径向力 F_r = Σ (P + q_r) ∂V/∂r_p，节点质量按 ∂V/∂r 的比例分配。因此球对称状态在每根辐条上（包括轴上）的演化与一维程序完全相同。
  - 角向力来自辐条两侧的压力差，按角动量 d(M r u_θ)/dt = r F_θ 积分，自动包含几何项。
  - 能量按相容格式计算：体积变化 = 径向部分 + 辐条扫过的体积，P dV 功分给电子、离子和辐射，粘性加热给离子。
- **角向重映射**：每步结束后辐条回到固定角度。质量、电子/离子比内能、辐射能和 DT 燃料按扫过体积做二阶（van Leer 限制）迎风输运，节点动量同样处理。重映射损失的动能还给离子，因此总能量守恒（基准中误差 10⁻¹²）。网格只在同一径向圈内交换物质，而材料是按圈定义的，所以不会出现混合网格。
- **辐条面压力重构**：网格圈倾斜后，同一圈相邻网格位于不同半径，直接取两侧网格压力差会混入背景径向压力梯度 × 倾斜量。这个伪切向力与 Rayleigh-Taylor 驱动同量级（会使不稳定分层变稳、稳定分层失稳）。因此先把每个网格的压力沿本列的限制径向梯度移到辐条面中点再求差，角向做功用同一面压力，能量仍严格守恒。
- **人工粘性与沙漏控制**：
  - 径向边粘性和角向边粘性只在压缩时起作用。纯径向会聚流不产生角向粘性。
  - 节点半径在 θ 方向的锯齿模式不改变网格体积，是零能模式。对它施加四阶差分恢复力，刚度与径向刚度相当，对低阶 l 模式的影响只有 (lΔθ)⁴ 量级。轴上和赤道上的节点用镜像邻点参与同一恢复力。
  - 径向人工粘性按辐条分别计算（每个网格的两条径向边各有一个 q），避免一根辐条上的冲击被相邻辐条的平均值抹掉。
  - 节点 u_θ 沿径向的锯齿同样是零能模式，用粘性型沙漏阻尼抑制。
  - **局限**：节点半径的角向锯齿是这种格式的零能模式，必须用弹性恢复力抑制（`Options2D.hourglass`，默认 0.05，四阶差分）。弹性力同样作用于低阶 l 模式，会压住 Rayleigh-Taylor 增长：球面 RT 基准中，默认设置下 l = 8 的扰动不增长；关闭后增长率达到理论值的 0.86，但 KrF 靶在 7–8 ns 出现网格尺度锯齿而崩溃。六阶差分、粘性型（`hourglass_order`、`hourglass_visc`）和更弱的弹性力都不能让靶稳定算完。因此 SIFE-2D 适合研究低阶（l ≲ 6）的照射不均匀和形变，不适合研究烧蚀面 RT 增长；后者用上面的 Godunov ALE 格式。
- **轴节点绑定**：轴上 (θ = 0) 的节点几乎没有受压面积，作为自由节点会跑到径向邻点前面并引发轴向射流。它们与相邻辐条的节点合并质量和力，径向上作为刚体一起运动（`Options2D.axis_tie`）。
- **准一维核心（`core_rings`）**：最内若干圈不做角向运动，比内能和燃料按圈做质量平均，相当于等压热斑近似。它去掉了球心细锥网格的角向 CFL 限制。KrF 靶默认把整个气体区（热斑）都设为核心：热斑声速很高，接近等压；若让低密度热斑气体自由做角向运动，它在滞止时会被高速剪切流拧坏，网格相交（P2 和 l = 6 扰动算例在 9.6–9.8 ns 因此崩溃）。热斑的形状仍由每根辐条上独立运动的冰/气界面给出，但热斑内部的角向流动（例如射流穿入热斑）不被模拟。
- **为什么不用一般四边形网格**：最早实现的是一般 (z, R) 四边形拉格朗日格式（面积加权或控制体积力）。它在球心三角形网格和对称轴上会产生 O(1) 的能量误差或轴向射流，Sedov 能量误差达到 20%，所以改成了现在的球坐标 ALE 格式。

### 其它物理在二维中的处理

- **扩散**（`diffusion2d.py`）：维度分裂。先对每一圈做角向隐式扩散（Te、Ti、Er 各自三对角求解），再对每一列做与一维完全相同的径向三温耦合隐式求解（热传导、e-i 交换、辐射发射/吸收、激光和 α 源）。两步都无条件稳定且守恒；各列、各圈用 numba 多线程并行。
- **激光**：扇区近似。每一列按局部球对称大气调用一维射线追踪器，扇区功率 ∝ 立体角 × 照明强度 I(θ) = 1 + Σ a_l P_l(cosθ)。这种近似忽略了光线的横向折射。
- **燃烧与 α 粒子**：燃烧逐网格计算。α 输运沿每一列用一维多角度慢化模型（扇区近似），忽略横向输运。
- **扰动种子**：
  - 照明不均匀性 a_l；
  - 任意界面的 Legendre 形变 ε_l P_l(cosθ)，位移在相邻界面处线性衰减到 0。

### 时间步

一维的全部限制加上角向 CFL：r Δθ / (c_s + |u_θ|)，核心圈不受角向 CFL 限制。不设核心时，滞止阶段的最小步长由中心网格的角向尺寸决定，比一维小一个量级以上。

### 二维基准（`benchmarks/*2d.py`）

| 基准 | 检验内容 |
|---|---|
| Sedov 点爆炸 | 激波半径、各角向对称性、能量守恒 |
| Noh 球形内爆 | 强会聚冲击、对称性 |
| l = 2 声学本征模 | 角向压力梯度、角动量、重映射：振荡周期与振幅 |
| l = 2 热传导模式衰减 | 径向和角向隐式扫描的组合精度 |
| 球面 Rayleigh-Taylor（`rt2d.py`） | 重壳 + 均匀径向重力，P_l 界面扰动的线性增长率对比解析解 γ² = (g/R) l(l+1)(ρ₂−ρ₁)/(lρ₂+(l+1)ρ₁)；同时比较 ALE 和旧格式 |

## 运行

```bash
pip install numpy scipy numba matplotlib
python benchmarks/run_all.py              # 全部验证算例 -> output/benchmarks/
python examples/krf_target.py             # KrF 点火靶 -> output/krf/
python examples/plot_krf.py output/krf    # 作图
python -m sife.animate output/krf         # 一维动画 -> implosion.mp4 / .gif
python examples/krf_target_2d.py --out output/krf2d --illum 2:0.03     # 二维 (P2 照明不均匀 3%)
python -m sife.animate output/krf2d       # 二维动画 -> implosion2d.mp4 / .gif
```

二维参数：`--nth` 角向网格数（半球默认 16），`--full` 计算整个 0–π，`--illum l:a` 照明 Legendre 模式，`--pert k:l:amp_um` 界面 k（0 为气/冰，1 为冰/烧蚀层，2 为外表面）的 P_l 形变，`--zone-scale` 径向分辨率倍数，`--rough k:lmin:lmax:rms_um` 多模粗糙度（随机幅度，平谱），`--hg/--hgo/--hgv` 沙漏控制参数（仅供试验）。半球计算（默认）只能表示关于赤道对称的模式。

Q 值：`summary.json` 中的 `Q` 字段，定义见 `sife/qvalue.py`（Q_target = E_fus/E_laser，Q_abs = E_fus/E_abs，Q_fuel = E_fus/燃料峰值动能，ηG，工程 Q = η_th·M·η_d·G）。

自定义靶与脉冲：写一个 json 覆盖 `examples/krf_target.py` 中的 `DEFAULT` 字段，例如：

```json
{"d_ice": 0.03, "t_ns": [0, 0.2, 4, 9, 12, 12.2], "P_TW": [0, 5, 5, 350, 350, 0]}
```

然后运行 `python examples/krf_target.py --params my.json --out output/my_run`。
